# Clip-Led Clark Celebration Playbook

This is the default FTL format for game footage.

The goal is not to recap whether Indiana won or lost, or even whether Caitlin Clark had a perfect game. The goal is to positively break down Caitlin Clark's best available possessions from that game, hype the value she created, and prove why she is the channel.

## Editorial Rule

Caitlin Clark is the product.

If Clark plays, the game is usable when there are enough possessions to explain. A win or huge stat line is a bonus, not a requirement. A loss, off shooting night, or messy team game can be mentioned only as context. It is never the emotional frame. The viewer clicked for Clark's reads, range, handle, pace, passing, gravity, and the way she bends the defense.

## When To Use This

Use this format for:

- Any game where Clark has a strong stat line.
- Any game with 6-12 clear Clark highlights.
- Any game where Clark's passing, gravity, pace, or decision-making created quality possessions even if the box score was not loud.
- Any loss where Clark still created elite plays.
- Offseason compilations built from archived Clark highlights.
- Skill-specific breakdowns: logo threes, transition passing, no-look assists, handle, late-clock shot creation.

Do not wait for wins. Do not wait for perfect games. Our job is to find the possessions that show how good Clark is and explain them clearly.

## Core Formula

The format is footage first:

```text
PLAY ON SCREEN
defensive mistake
Clark read
Clark punishment
reaction/payoff
NEXT PLAY
```

The script follows the clip. It does not force clips to follow a prewritten essay.

## Structure

### 1. Verdict Hook

Open with the title claim in one sentence.

Examples:

- Caitlin Clark's fourth quarter was unreal.
- Caitlin Clark was way too comfortable from the logo.
- Caitlin Clark turned one defensive mistake into an entire highlight reel.

Then immediately show the best play.

### 2. Best Play First

Start with the strongest proof, not chronological order.

For a late-game video, this is usually:

- game-tying three
- go-ahead three
- no-look pass
- logo three
- impossible finish

### 3. Proof Stack

Use 8-12 plays. Each play gets 20-35 seconds.

Each beat must answer:

- What did the defender or coverage do?
- What did Clark see?
- How did Clark punish it?
- Why is that special?

### 4. Positive Clark Frame Only

Every beat should make Clark's value clearer.

Allowed:

- The defense was late.
- The coverage was confused.
- The big was in no-man's land.
- The weak side had to choose between Clark and the roll.
- Washington survived the game, but not this possession.
- That box score does not show the help defender she moved.
- The shot missed, but the read was the point.
- The possession worked because Clark collapsed the first defender.

Avoid:

- Framing Clark as failed because the team lost.
- Framing Clark as failed because one shot missed.
- Long complaints about teammates.
- Long game recap sections.
- Explaining the other team's win as the main story.

### 5. Ending

Close once the point is proven.

The ending should be a title callback, not a summary:

```text
That is not just a great fourth quarter.
That is Caitlin Clark making every normal defensive rule feel fake.
```

## VO Style

Borrow the useful parts of Awful Coaching:

- "Watch the defender..."
- "Freeze it here..."
- "That half step is already too late..."
- "Now Clark has the angle..."
- "And that is the punishment..."

But keep FTL energy:

- more awe
- more fan reaction
- less pure coaching tape
- fewer repeated filler phrases

## Edit Rules

- Use the actual play as the main visual.
- Freeze only when pointing to a defender, spacing, clock, or passing lane.
- Add one simple overlay at a time: arrow, circle, distance line, clock/score receipt.
- Moving clips should change every 5-10 seconds unless holding a freeze for analysis.
- Replays must reveal something new.
- Do not let the loss reaction become the ending unless the VO reframes it as Clark leaving proof on the floor.

## Current FTL Standard

For game-based Celebration videos, this playbook supersedes the older essay-first approach. The script must be built from verified clips before VO.
